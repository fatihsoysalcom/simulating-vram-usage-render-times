# Simulating VRAM Usage Render Times

This Python script simulates how increasing scene complexity impacts memory usage and render times, conceptually demonstrating VRAM requirements in 3D rendering. It allocates large NumPy arrays to represent scene data and performs computationally intensive operations, showing how larger data sets lead to longer processing times and higher memory consumption, mimicking VRAM bottlenecks.

## Language

`python`

## How to Run

1. Ensure Python and NumPy are installed (`pip install numpy`).
2. Run the script from your terminal: `python main.py`
